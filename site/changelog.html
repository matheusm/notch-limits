Changelog

What changed in each version, newest first. Downloads and release files are on GitHub Releases, which also has a feed if you want to follow new versions.

v1.1.0

2 November 2026

  • Accounts found automatically. Claude Code config folders such as ~/.claude-work that contain a .claude.json, and Codex homes such as ~/.codex that contain an auth.json, show up at launch and whenever you open Settings. No JSON to write; folders kept anywhere else still go in accounts.json by hand.
  • A Settings window. Open it with the gear in the expanded notch or the menu bar panel. Show, hide, rename, reorder and pick an icon for each account. Changes apply at once, with no restart and no network request, and are saved to ~/.config/notch-limits/accounts.json. A file you wrote by hand is copied to accounts.json.bak before Settings first overwrites it.
  • Pace on every bar. A faint tick on each bar in the notch panel marks where usage would be if spread evenly over the window. Under any window you're on track to hit before it resets, a line says when: "At this pace: limit today 4:26 PM". It's a straight-line projection from the latest reading, shown once 15% of the window has passed.
  • Best now. With two or more accounts of the same provider, the expanded panel tags the one with the most headroom. Claude and Codex accounts are ranked separately.
  • Optional notifications. A heads-up when a limit reaches 90%, and another when a limit you hit resets ("Claude Work is available again"). Off by default; turn them on in Settings. Text-only, with no sound and no extra network requests.

v1.0.1

2 November 2026

  • A polished installer. The DMG opens a branded window with large icons, a drag arrow and a shortcut to Applications.
  • Renamed to Notch Limits. The app is now Notch Limits.app. The one-line installer and build.sh remove the old NotchLimits.app.

v1.0.0

2 November 2026

  • First public release: Claude Code and Codex usage limits at the MacBook notch.
  • One ring per account, expanding on hover into every limit window (5-hour session, weekly, per-model) with its reset time.
  • Multiple accounts: Claude Code accounts through CLAUDE_CONFIG_DIR, plus Codex, configured in ~/.config/notch-limits/accounts.json.
  • Local-first: reads the usage snapshots Claude Code and Codex already write to disk, calls the usage API only when that data is more than 10 minutes old, and honors Retry-After.
  • Data age on every account, and color only at 70% and 90%.
  • Menu bar fallback on Macs without a notch, and launch at login.
  • English, Português and Español, following your system language.
